# Clinic Tracker — AOD Testing & Workplace Health System

Web-based application for managing workplace drug & alcohol testing, patient tracking, training records, and compliance reporting.

## 🚀 Quick Deployment (Clinic Environment)

### For Small Clinics (2-10 computers, no server needed)

**Option 1: One PC as Server (Recommended)**
```powershell
# 1. On your main PC, run:
INSTALL.bat                    # One-time setup
start-clinic-server.bat        # Start the server

# 2. On other clinic PCs, open browser:
# http://[main-pc-ip]:8080
# (Find IP with: ipconfig)
```

**Option 2: Desktop App (Single User)**
```bash
cd controller
npm install && npm run pack
# Run the generated .exe installer
```

## Quick Start (Development)

### Option 1: Double-click launcher (Windows)
```
start.bat
```

### Option 2: Manual
```bash
npm install                    # frontend deps
cd server && npm install       # backend deps
cd ..
npm run build                  # build frontend
set SERVE_FRONTEND=1 && node server/index.js
```

### Option 3: Desktop controller (Electron)
```bash
cd controller && npm install && npm start
```
See [controller/README.md](controller/README.md) for details.

Open **http://localhost:8080** — login with `admin` / `admin123`.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React, Vite, TailwindCSS |
| Backend | Node.js, Express |
| Database | SQLite (sql.js) — portable, zero-config |
| Desktop | Electron (optional Server Controller) |
| Tests | Vitest (server), Playwright (E2E) |

## Core Features

- **AOD Test Recording** — BAC, oral fluid, urine with auto-computed outcomes
- **Workflow Engine** — Non-Negative → RFT → Lab Confirmation → Medication Review
- **Pending Lab Tracking** — track samples sent to laboratory
- **Non-Negative Case Management** — follow-up actions and status tracking
- **Random Test Selection** — import worker lists, generate random selections
- **Scheduling & DNA Log** — daily scheduling, attendance, did-not-attend logging
- **Patient/Injury Tracker** — clinic visits, injuries, RTW plans, referrals
- **Training Tracker** — CPD records, competency units, ESO reporting
- **Reports Hub** — pre-built reports + custom report builder with Excel export
- **Settings** — manage test types, clinicians, employers, training units
- **Audit Trail** — full logging of all create/update/delete actions
